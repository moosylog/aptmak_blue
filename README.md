# Aptmak Blue Keyboard Layout

**Aptmak Blue** is a mirrored, multilingual keyboard layout based on the original [Aptmak](https://forum.colemak.com/topic/2999-apsus-aptmak-ergonomic-layout-for-english/) layout by Eve (Apsu). Developed in 2024 by Moosy, it is designed for **split and ortholinear keyboards**, optimized for both **English** and **Dutch** typing.  [Official Aptmak Blue here](https://sites.google.com/view/keyboards/layout/aptmak-blue).

## 💡 Key Features

- **Ergonomically optimized**: Minimizes pinky strain and awkward finger rolls.
- **Multilingual support**: Designed with both English and Dutch frequency patterns in mind.
- **Mirrored layout**: Makes better use of symmetrical keyboard designs.
- **Improved hand alternation**: Smooth rhythm and balanced finger usage.
- **QWERTY-friendly anchors**: Keys like A, Q, Z, /, and " remain in familiar positions.

---

## 🔤 Layout Philosophy

Aptmak Blue builds on the foundation of Colemak and Aptmak with enhancements specific to bilingual users. Key improvements include:

- Moving high-frequency letters (like `E`) to easier positions.
- Placing Dutch bigrams (`ij`, `ou`, `jul`) in more natural rolls.
- Reducing overuse of the right pinky by reassigning keys like `X`.
- Reversing comma/dot to better align with intuitive typing flow.
